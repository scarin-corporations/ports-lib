# Sponsorship setup

The repository includes `.github/FUNDING.yml` pointing to `scarin-corporations` so GitHub can show a Sponsor button after the organization activates GitHub Sponsors.

The organization profile currently has no active Sponsors page. An organization owner must enroll at <https://github.com/sponsors/accounts>, complete GitHub's eligibility, tax, and payout steps, and wait for approval. Once the public page at <https://github.com/sponsors/scarin-corporations> offers sponsorship tiers, the repository funding link is ready. This repository configuration cannot enroll the organization or create payout details on its behalf.

Keep sponsorship voluntary. Do not imply that sponsorship grants rights to copyrighted games or guarantee project compatibility.
